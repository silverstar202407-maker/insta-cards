## 릴스 (매일 3개: 08·15·22시)
- 릴스는 카드뉴스 1개당 1개: 08시 = 그날 03시 글, 15시 = 그날 12시 글, 22시 = 그날 18시 글의 '예고편'.
- 릴스는 흥미 유도용(사용자 결정): 움직이지 않는 정지 이미지 한 장 안에 제목 + story.json 의 "teaser"(3~5문단, 결말 없이 궁금한 지점에서 끊고 마지막 문장은 R) + "뒷이야기는 프로필에서"를 모두 넣는다. 3초(인스타 최소 길이), 배경 웅웅 소리 유지.
- 릴스 양식(사용자 결정, 2026-11-20): 본문 글씨 30(강조 31), 줄 간격 50, 줄 길이 720px 안에서 문장마다 줄바꿈(긴 문장은 고르게 나눔). 예전 양식으로 미리 만든 reel 파일이 있어도 게시 전에 항상 다시 만든다.
- 만들기: python3 tools/goeirok_reel.py goeirok/stories/{slug}.json goeirok/posts/{slug} → reel.mp4, reel_cover.jpg, reel_caption.txt (ffmpeg 필요)
- reels_posted.txt: "{날짜} {시} {slug} {제목}" 릴스 게시 기록(예전 줄은 "{날짜} {slug} {제목}"). 같은 slug 는 두 번 올리지 않는다.
